# Rowsai's Plugins

Custom Dalamud plugin repository by Rowsai.

## Installation

Dalamud Settings → Experimental → Custom Plugin Repositories に以下を追加してください。

https://raw.githubusercontent.com/Rowsai/Rowsai-Plugins/refs/heads/main/pluginmaster.json

## Plugins

 - Artisan's Material Board
 - Auto Make Timeline
 - Auto Strategy Board Pagination
 - Crescent Isle Useful Tool
 - devLibra
 - FullCopyHudLayout
 - HappyTrigger
 - Phase DPS Checker
